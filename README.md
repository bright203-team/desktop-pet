# デスクトップペット

**AI（Codex / Claude Code）へ：このリンクで頼まれたら [AGENTS.md](AGENTS.md) の手順に従ってください。** 最初に対象環境と希望をまとめて確認し、返事のあとは導入・起動確認までAIが行います。

Claude・ChatGPT のデスクトップアプリの手前に、フランとシフォンが常駐します。マウスで触ると動き、Claude Code・Codex の hooks を登録すると作業中・入力待ち・完了に合わせて反応します。アプリ本体は変更しません。

## 動作環境

- Windows 10・11。macOS・Linux デスクトップには対応していません。
- Python 3.14（Python Launcher の `py` を含む）、Node.js 22 以上。
- PySide6 6.12.0 は導入時に自動でインストールします。そのときだけインターネット接続が必要です。起動後のネットワーク通信はありません。
- Claude または ChatGPT のデスクトップアプリ。hooks の連動には Claude Code または hooks に対応した Codex を使います。

## 入れ方・更新・削除

ZIP を展開し、展開先で PowerShell を開いて実行してください。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./scripts/install.ps1
```

フランとシフォンの絵も含まれています。Git・GitHub・開発用のハーネスは不要です。詳しい操作は [導入の手引き](INSTALL.md) を参照してください。

## hooks の登録

Claude Code の hooks は既定で導入時に登録します（不要なら `-NoClaude`）。Codex の Windows / WSL の hooks とログイン時の自動起動は、導入時の質問で選べます。他の hooks は保ったまま、このペットの登録だけを追加・更新します。

導入後は Claude Code の新しいセッションを開いてください。通常のチャット画面だけでは作業状態は連動しません。

### 導入後の必須ステップ：Codex の hooks を信頼する

Codex デスクトップアプリでは「設定 → フック → ユーザー設定」を開き、ペット用5件（UserPromptSubmit・PreToolUse・PermissionRequest・PostToolUse・Stop）がそれぞれ「有効」かつ「信頼済み」になっているか確認します。未信頼なら、その内容を確認して信頼してください。設定後は新しいチャットで動作を確かめます。通常の利用でターミナルを開いておく必要はありません。
Codex CLI と連動する場合は、導入のあと、Codex で `/hooks` を開き、同じ5件を信頼し、新しいセッションを始めてください。
Codex は信頼していない hooks を実行しないため、信頼しないと連動しません。
WSL の Codex を使う人も、WSL 側の Codex で同じ手順を行ってください。

ペットの「設定…」には、Claude Code・Codex Windows・Codex WSL ごとの「登録なし」「登録済み・まだ通知なし」「連動中（最後に通知を受け取った時刻）」を表示します。時刻は状態ファイルの更新時刻で、古い通知でも受信履歴として残ります。現在の接続や信頼を保証する表示ではありません。Codex の最終通知は Windows・WSL 共通で、WSL の登録は導入時の記録から表示します。「登録済み・まだ通知なし」の「確認手順…」から上記の案内を開けます。

「連携テスト」を押すと、選択したキャラが「作業中 → 返事待ち → 完了」を各3秒表示し、元の状態へ戻ります。途中で実際の通知が届いた場合は最新の状態へ戻ります。設定画面を閉じてもテストを終了できます。キャラを表示し、表示先のアプリを開いて確かめてください。これはペット内だけの見た目のテストで、設定や状態ファイルの変更・通信はしません。実際の hooks の連動は、新しいチャットで最終通知の時刻が更新されることを確かめます。

## キャラと設定

通知領域のアイコンを右クリックして「設定…」を開きます。表示・大きさ・透明度・連動先・動き・オーラ・自動起動を変更できます。「アニメのプレビュー」で場面を確認できます。

「キャラを追加」で名前と見た目を入力し、画像作成用の日本語プロンプトをコピーします。画像は別のツールで作成し、同じ画面から取り込んでください。アプリ内で画像生成や通信はしません。Codex Pets の v1 / v2 スプライトシートや、指定形式の個別 PNG を取り込めます。

設定・保存位置・追加キャラは `%USERPROFILE%/.claude-desktop-pet/` に保存されます。設定は更新や通常の削除でも保持します。
